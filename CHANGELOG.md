## [0.1.0] - 2026-08-12

### Added

- Read-only, bounded local repository discovery with no runtime dependencies.
- Multi-vendor instruction inventory for AGENTS.md, Claude Code, Gemini CLI, GitHub Copilot, and Cursor surfaces.
- Verification path inventory with source provenance, confidence, and no command execution.
- Python, Node.js, Rust, Go, PowerShell, generic manifest, lockfile, CI, and orientation signals.
- Console, JSON schema version 1, and Markdown reports.
- Transparent optional evidence score with fixed category caps.
- Sensitive-path skipping, credential-pattern redaction, relative paths, and a public fake-canary regression suite.
- Cross-platform Python 3.11 and 3.13 CI plus tagged wheel/sdist release automation.
